# Jiaqi Cheng — Personal Site

Source for [jackson9413.github.io](https://jackson9413.github.io).

## Stack
- Pure HTML + Tailwind (via CDN)
- No build step
- Hosted on GitHub Pages

## Local preview
```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy
Pushes to `main` automatically publish to GitHub Pages.

## Updating
- Edit `index.html` directly
- Replace `Jack_Cheng_CV.pdf` to update the CV download
- Commit + push — live in ~30s
